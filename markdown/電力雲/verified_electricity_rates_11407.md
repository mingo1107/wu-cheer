
# 114年7月 特高壓電力 (三段式) 費率驗表

以下為用於驗算帳單金額 (114年7月，夏月) 之精確費率參數。

## 1. 基本電費 (Capacity Charge)
- **經常契約單價 (夏月)**：`223.6` 元/kW
- **半尖峰契約單價**：`38.15` 元/kW (依帳單逆推之特殊費率)

## 2. 流動電費 (Energy Charge)
針對數百萬度用電量進行驗算後，得出的吻合費率如下：

| 時段別 (Time of Use) | 費率 (元/度) | 說明 |
| :--- | :--- | :--- |
| **尖峰 (Peak)** | **8.865** | 16:00~22:00 (夏月) |
| **半尖峰 (Half-Peak)** | **5.474** | 09:00~16:00, 22:00~24:00 (夏月) |
| **週六半尖峰 (Sat)** | **2.256** | 週六全日 |
| **離峰 (Off-Peak)** | **2.256** | 00:00~09:00 (每日) & 週日全日 |

*(註：此費率精確至小數點後三位，用於解決特高壓大用電量下的金額誤差)*

## 3. 超約附加費 (Penalty Calculation)
對於特高壓用戶，不同時段的超約罰金採取 **累加計算** (與一般高壓取各時段最大值不同)。

- **經常需量超約**：若被半尖峰超約量覆蓋則不重複計收。
- **半尖峰需量超約**：本次帳單主要罰金來源。
- **離峰/週六需量超約**：視為獨立時段，罰金外加。

**公式**：
$$ \text{總罰金} = \max(\text{經常罰金}, \text{半尖峰罰金}) + \text{離峰罰金} $$
